L4D 맵 구조 전체 교체 v3
Unity 6 / URP / AI Navigation 2.x용 Editor 도구

적용 순서
1. 이 unitypackage의 파일을 모두 Import합니다.
2. 현재 작업 중인 L4D 씬 하나만 열고 Play를 멈춥니다.
3. Tools > L4D 맵 > 맵 구조 전체 교체 (v3)를 엽니다.
4. 환경 에셋 폴더가 Assets/Flooded_Grounds인지 확인합니다.
5. [이 구조로 실제 맵 교체]를 누릅니다. 경로 생성과 검사가 끝날 때까지 기다립니다.
6. Console의 [L4D 구조 교체 완료]와 창의 교체·저장 완료 표시를 확인하고 Play합니다.

무엇이 달라지나
- 기존 도로를 안내선으로 덮는 방식이 아닙니다. 기존 배치를 새 도로·건물·충돌 배치로 교체합니다.
- 출발 안전가옥 → 주택가 → 공장·창고 → 중간 안전가옥 → 수로 다리 → 폐차장 → 구조 광장 → 탈출 순서입니다.
- 서로 붙은 왕복 구간과 교차로를 없애고, 크게 꺾이며 한 방향으로 전진합니다.
- 기본 중앙 동선: 피날레까지 약 1.96km, 탈출까지 약 2.05km입니다.
- 중앙선 길이뿐 아니라 실제 NavMesh 최단 경로가 기존 전체 경로보다 짧아지지 않는지 검사합니다.
- 기존 맵이 더 길면 전체 배치를 비례 확대합니다.
- 기존 Flooded Grounds 모델과 텍스처를 사용합니다. 완성 건물이 벽·지붕 모듈의 조합인 경우 기존 씬의 붙어 있는 부품을 묶어 재사용합니다.
- 큰 에셋을 다시 다운로드하거나 업로드할 필요가 없습니다.

게임 연결
- CityMapInfo와 기존 NavMeshSurface 컴포넌트 자체는 유지합니다.
- 시작 위치, 안전가옥, 진행 경로, 좀비 스폰, 라디오, 피날레, 탈출 위치를 새 배치에 연결합니다.
- AI 디렉터의 맵 참조도 현재 CityMapInfo로 지정합니다.
- 기존 보급 시스템이 새 경로의 20/40/60/80% 지점과 안전가옥 마커를 사용합니다.
- 기존 E키 무기 습득, 1인칭 무기, 동료, 조준점 타격 효과, 사운드 코드는 덮어쓰지 않습니다.
- 기존 안내선 v2 오브젝트와 구버전 배치는 경로 검사를 통과한 뒤 씬에서 삭제합니다.
- 원본 환경 모델·텍스처·프리팹 에셋 파일은 삭제하지 않습니다.

충돌과 부하
- 진행 중앙을 비워 두고 건물·차량을 양옆에 배치합니다.
- 건물 묶음마다 충돌 상자 하나를 사용하고, 바닥과 외곽 펜스에는 실제 모양의 MeshCollider를 사용합니다.
- 장식 모델의 불필요한 스크립트·조명·물리 컴포넌트는 배치된 복사본에서 정리합니다.
- 새 가로등은 그림자를 끄며, 장식 건물은 정적 배칭 대상으로 표시합니다.
- 실제 프레임 개선 폭은 프로젝트에서 측정해야 합니다. 이 도구는 FPS 개선 수치를 보장하지 않습니다.

실패·복원
- 실행 직전 현재 씬을 저장하고 Library/L4D_LinearRebuild/날짜_번호/에 씬과 meta를 복사합니다.
- NavMesh 경로·미션 연결·스폰·중앙 통로의 캡슐 충돌 검사에 실패하면 원래 씬을 다시 엽니다.
- 완료 후 이전 배치로 돌아가려면 같은 창의 [직전 교체 전 씬으로 복원]을 누릅니다.
- 생성 결과와 검사 보고서는 Assets/L4D_LinearCampaignGenerated/Build_날짜_번호/에 있습니다.
- 검증용 건물 묶음을 찾지 못하면 기존 씬을 변경하지 않고 중단합니다. 현재 맵 씬과 환경 폴더를 확인하세요.

검증 범위
제작 환경에는 Unity Editor와 전체 Flooded Grounds 모델이 없습니다.
따라서 여기서는 C# 문법, 실제 업로드 씬의 필드, 독립적인 바닥 연결·거리 계산, 패키지 무결성을 확인했습니다.
Unity 컴파일, 실제 건물 묶음 인식, NavMesh 베이크, 화면 렌더링, 플레이는 사용자의 프로젝트에서 확인해야 합니다.
패키지를 가져오는 것만으로 맵이 바뀌지 않습니다. 반드시 위 메뉴에서 교체 버튼을 눌러야 합니다.
