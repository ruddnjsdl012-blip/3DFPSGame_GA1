L4D 속도 6 / 탱크 전용 체력바 v3 수정 내역 — 2026-10-29

적용 방법
1. Unity에서 Play를 끈다.
2. Assets > Import Package > Custom Package에서 이 unitypackage를 선택하고 Import한다.
3. Assets/01.Scenes/L4D.unity를 다시 열고 Play한다.
기존 씬과 스크립트에 적용하는 업데이트 패키지다. 새 프로젝트용 전체 프로젝트 파일은 아니다.
맵 형상과 NavMesh 데이터는 바꾸지 않았으므로 이 업데이트 때문에 NavMesh를 다시 구울 필요는 없다.

체력바
- 일반 좀비/러너/부머/스피터: 프리팹의 HealthBarCanvas를 기본 비활성화하고 실행 시에도 Canvas와 갱신 컴포넌트를 끈다.
- 탱크: 화면 위 DirectorHUD 보스 체력바, 체력 700, 피격/처치 연결을 유지한다.
- 탱크의 머리 위 체력바와 화면 위 보스 체력바만 유지한다. SetVisible(true)를 호출해도 탱크가 아니면 표시되지 않게 제한한다.
- 체력바용 Camera 참조를 저장하고, 체력이 달라졌을 때만 Slider 값을 갱신한다.

최적화
- Zombie: 항상 추격 설정을 유지한다. 12m 안은 약 0.07초, 중거리는 약 0.15초, 25m 밖은 약 0.3초 간격으로 현재 플레이어 위치를 갱신한다.
- 일반 좀비 속도를 6으로 설정한다. 가속도 28, 회전 속도 900, 빠른 재추격 반응을 유지한다. 러너/부머/스피터/탱크의 고유 이동속도는 변경하지 않는다.
- 추격 시작, 공격 범위 이탈, 피격 경직 종료 때는 갱신 타이머를 기다리지 않고 즉시 새 목적지를 요청한다.
- 이전 목적지에 도착해도 플레이어가 이동했다면 즉시 목적지를 갱신한다.
- 첫 공격 전 1.2초 대기를 제거한다. 재공격 간격은 유지하고, 공격을 취소하고 다시 접근해도 간격을 초기화하지 않는다.
- 일반 좀비 피격 경직은 0.5초 → 0.18초. 특수 좀비의 피격 경직 시간은 유지한다.
- 달리기 복귀 시 남은 공격 트리거를 지우고 Move 상태로 0.06초 동안 전환한다.
- 공격 취소 후 남은 애니메이션 이벤트나 공격 범위 밖 이벤트로 원격 대미지가 발생하지 않게 막는다.
- 유효한 경로가 있고 목적지 변화가 0.1m 미만이면 경로 재요청을 생략한다. 경로 계산 대기 중 재요청도 생략한다.
- 정지 상태에서 ResetPath를 계속 반복하지 않는다. 특수 좀비의 능력 사용 중 정지도 보존한다.
- 화면 밖 좀비는 Animator CullUpdateTransforms로 뼈 변환 작업을 줄인다. CullCompletely는 쓰지 않는다.
- ZombieModelLock: 화면에 보이지 않는 모델의 바닥/뼈 보정을 생략하고, 바닥 판정 결과 배열을 재사용한다. 버퍼가 꽉 찰 때는 정확한 판정으로 대체한다.
- ZombieUnstuck: 검사 시점을 분산하고, path/corners 배열 복사 대신 steeringTarget을 쓴다.
- MinimapCamera: 기존 RenderTexture 화면을 유지하면서 초당 최대 약 15회 렌더링한다. 줌 버튼/키는 그대로 사용한다.
- 미니맵 카메라: 그림자, HDR, MSAA, 불필요한 Depth/Opaque 복사를 끄고 far clip을 64로 줄인다.
- 메인 카메라: 안개가 완전히 덮이는 거리 170m 바깥을 고려해 far clip 1000을 200으로 줄인다.
- GameSounds.PlayAt: 매번 오브젝트를 생성/파괴하지 않고 최대 24개 AudioSource를 재사용한다. 꽉 찬 동안 추가 위치 효과음은 생략한다. 2D 총소리/탱크 경고는 별도다.
- Director: 숫자가 달라졌을 때만 좀비/처치 문구를 만들고, 피날레 타이머는 초가 바뀔 때만 바꾼다.
- Director: 스폰 후보 리스트를 재사용하고, 탱크 스폰이 실패해도 매 프레임 재시도하지 않는다.
- 일반 좀비의 반복 상태 전환 Debug.Log를 제거한다.
- 좀비 스폰 배율, 최대 개체 수, 공격력, 체력, 기존 무기 조작은 유지한다. 일반 좀비 이동 속도와 첫 공격 반응, 추격 복귀 반응을 위와 같이 변경한다.

현재 구현에서 확인되는 기능
호드, 긴장도 기반 디렉터, 러너/부머/스피터/탱크, 시작/중간 안전가옥, 보급품, 치료, 수류탄,
소총/도끼/리볼버, 헤드샷, 피격/혈흔 효과, 손전등, 구조 요청과 생존 타이머, 탈출 성공 처리가 있다.

부족한 점과 우선순위 — 제공된 씬/스크립트 기준
1. 전투 대응: 사용자의 방향에 따라 모든 일반 좀비는 항상 추격한다. 감지형 배회 AI로 바꾸지 않는다.
   다음 보강 후보는 밀치기, 장애물 넘기, 막힌 문 공격이다.
2. 동료와 소생: 동료 AI나 쓰러짐/소생 흐름은 확인되지 않는다. 현재 Player는 체력이 0이면 GameOver다.
   혼자 만드는 단계라면 온라인보다 동료 AI 한 명과 구조/소생을 먼저 만드는 편이 구현 범위를 잡기 좋다.
3. 맵 내 전투 목표: 구조 요청 후 생존 외에도 발전기 가동, 문 열기, 경보를 울려 길 뚫기 등 중간 목표가 필요하다.
4. 특수 좀비의 식별과 대응: 4종의 기본 능력은 있으므로 종류 추가보다 공격 예고, 약점, 회피/구출 방법을 다듬는 것을 권한다.
5. 디렉터의 전투 리듬: 현재 긴장도는 주로 피격 체력과 시간으로 계산된다. 주변 적 압박, 탄약, 이동 정체도 판단에 반영할 수 있다.
6. 대규모 군중: World War Z식 규모를 목표로 한다면 가까운 적만 전체 AI/물리/애니메이션을 계산하고, 먼 무리는 간소화하는 별도 구조가 필요하다.
   이번에는 기존 개체 수를 유지하며 반복 연산을 줄였다. 좀비 자체의 오브젝트 풀링과 군중 LOD는 아직 추가하지 않았다.
7. 완성도: 패배/클리어 뒤 재시작과 구간 재도전, 난이도 조절, 조작/그래픽/음량 옵션을 보강할 만하다.

확인 범위
- 패키지에 포함된 C# 파일 89개의 문법 구조와 씬/프리팹의 YAML 구조 및 로컬 참조를 검사한다.
- 탱크 HUD 갱신/사망 메서드, 탱크 능력치, 기존 무기/플레이어 원본을 대조한다.
- v2는 추격 시작/복귀, 첫 공격, 재공격 간격, 이전 목적지 도착 시 갱신 조건을 추가로 검사한다.
- v3는 일반 좀비 속도 6, 탱크 전용 체력바 표시 조건과 특수 좀비의 능력치/HUD 유지 여부를 검사한다.
- 이 작업 환경에는 Unity Editor가 없어 C#의 Unity 어셈블리 컴파일, 실제 플레이, FPS/프레임타임은 측정하지 못했다.
- ProjectSettings/URP 파이프라인 자산 전체가 포함되지 않아 해당 전역 설정과 실제 GPU 병목은 확인하지 못했다.
