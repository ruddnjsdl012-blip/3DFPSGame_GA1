L4D 우클릭 밀치기 · 프랍 경로 수정 · 어두운 분위기 v5 — 2026-10-29

적용
1. Unity의 Play를 끈다.
2. Assets > Import Package > Custom Package에서 이 패키지를 선택하고 모두 Import한다.
3. 기존 Assets/01.Scenes/L4D.unity 씬을 열어 Play한다.
자동으로 필요한 컴포넌트가 붙으므로 Inspector에서 따로 연결할 항목은 없다.
기존 프로젝트용 누적 패치다. 맵 씬·모델·저장된 NavMesh 파일은 패키지에 포함하지 않는다.

우클릭 밀치기
- 총을 들거나 장전 중이거나 도끼/수류탄을 들고 있어도 우클릭으로 밀친다.
- 우클릭을 누르고 있으면 0.65초 간격으로 반복한다.
- 전방 약 2.2m, 좌우 65도 안의 여러 좀비가 대상이다. 벽 뒤·등 뒤·다른 층의 대상은 제외한다.
- 탱크를 제외한 대상은 최대 약 1.35m 밀려나고 약 0.7초 멈칫한다. 체력 피해는 주지 않는다.
- 뒤에 벽/자동차/낭떠러지가 있으면 이동을 제한한다. 틈이 없을 때도 멈칫 효과는 적용한다.
- 밀친 좀비의 공격 애니메이션 이벤트는 피해를 주지 못한다. 멈칫이 끝나면 현재 플레이어를 다시 쫓는다.
- AR/리볼버의 재장전 코루틴과 탄약 처리는 그대로 진행한다. 밀치기 때문에 장전을 취소하거나 처음부터 다시 하지 않는다.
- 밀치는 짧은 동작 동안에는 총/도끼의 새 공격을 막고, 팔/무기를 앞으로 뻗는 자세와 효과음을 보여 준다.
- 수류탄 조작: 4번으로 들고 왼쪽 클릭을 떼서 던진다. 우클릭은 힘 모으기를 취소하고 밀친다.
  아직 손을 떠나지 않은 수류탄은 소비하지 않는다. 이미 던진 수류탄은 정상적으로 날아간다.
  1/2/3번이나 휠로 다른 무기로 돌아간다.
- 치료 중 우클릭은 치료를 취소하고 밀친다.

프랍 끼임 대응
- CityMapInfo.Awake에서 현재 활성 맵의 콜라이더를 기준으로 이동 경로를 한 번 다시 만든다.
  Play/맵 로딩 시작 때만 실행하므로 시작 시 잠깐 준비 시간이 생길 수 있다. 플레이 중 매 프레임 재생성하지 않는다.
- 기존 콜라이더를 우선 사용하고, 콜라이더가 없는 높이 0.35m 이상의 모델은 박스 콜라이더로 보강한다.
- Props/Buildings의 충돌체 윗면을 Not Walkable로 지정한다. 자동차 지붕/프랍 안을 이동 목표로 쓰는 것을 방지한다.
- Ground/Elevated의 경사로·주차타워·고가도로는 이 제외 처리의 대상이 아니다.
- 플레이어/좀비 레이어는 경로 굽기에서 제외한다. 움직이거나 파괴되는 드럼통/상자는 동적 Carving 장애물로 처리한다.
- 좀비 생성 전 완전한 경로와 실제 캡슐 공간을 함께 확인한다.
- 밀쳐짐과 끼임 복구의 이동은 NavMesh 경계와 물리 캡슐 스윕을 모두 확인한다.
- 약 1초 동안 추격 이동이 막히면 네 방향의 짧은 우회 동작과 경로 재요청을 시도한다.
- 군중 회피 우선순위를 잠깐 바꿔 통로의 상호 대기를 줄인다.
- 실제 프랍 옆면과 겹쳤으면 다른 벽을 넘지 않는 범위에서 분리를 시도한다.
- NavMesh에서 벗어난 경우 같은 층·2m 이내의 비어 있는 지점을 검사해 다시 연결한다.
  플레이어/다음 경로 모퉁이로 순간이동시키지 않는다.

분위기
- 태양/달 역할의 방향광 밝기를 기존의 70%로 낮춘다.
- 하늘·환경광·안개·반사 밝기도 조금 낮춘다. 가로등·안전가옥·손전등 밝기는 유지한다.
- 실행 중 사용할 하늘 재질을 복제하므로 원본 재질 에셋은 수정하지 않는다.

기존 요청 유지
- 일반 좀비 이동 속도 6, 항상 추격.
- 일반/러너/부머/스피터의 체력바는 숨기고 탱크의 체력바와 보스 HUD는 유지한다.
- 특수 좀비의 고유 속도/체력/공격력은 유지한다.
- 기존 추격 반응, 경로 재요청, 효과음 재사용, 미니맵과 UI 최적화도 포함한다.

검사 범위
- 프로젝트 C# 94개 파일의 구문을 파싱해 오류가 없는지 검사했다.
- 실제 C# 메서드의 제어 흐름을 모의 입력으로 실행하는 29개 시나리오를 통과했다.
  장전 유지/쿨다운/단일 타격/다중 좀비/밀치기 저항/공격 억제/추격 복귀/경계 및 벽 이동 제한 등을 포함한다.
- 제공받은 씬의 자동차 40대가 충돌체를 갖고 있으며 새 Props 경로 제외 처리에 포함되는지 검사했다.
- 기존 씬/저장된 NavMesh/플레이어 이동 설정/좀비 속도6 프리팹을 보존했다.
- Unity Editor가 없는 환경이므로 Unity 어셈블리 컴파일, 실제 맵 플레이, NavMesh 베이크 결과와 FPS 측정은 하지 못했다.
  모의 검사와 구문 검사는 실제 Unity 물리 및 플레이 검증을 대신하지 않는다.

Unity에서 빠르게 확인할 항목
1. AR의 탄창을 일부 쓴 뒤 R로 장전하고 도중 우클릭: 밀치기가 나오며 원래 장전 시간에 탄약이 채워지는지.
2. 전방 여러 일반 좀비가 밀리고, 뒤쪽/벽 너머 좀비와 탱크는 밀리지 않는지.
3. 자동차 둘레·건물 모서리·좁은 통로를 돌아 이동할 때 좀비가 우회하고 계속 추격하는지.
4. 밀친 좀비가 벽이나 차를 통과하지 않고 멈칫 후 다시 접근하는지.
5. 조금 어두워진 맵에서 가로등·안전가옥과 F 손전등으로 이동 방향을 읽을 수 있는지.
