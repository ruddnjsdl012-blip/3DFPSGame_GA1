L4D 동료 AI · 추적/전투/대기 v9 — 2026-10-30

적용 방법
1. Unity의 Play를 끈다.
2. Assets > Import Package > Custom Package에서 이 패키지를 선택하고 전체 Import한다.
3. 자동 소스 적용과 이어지는 컴파일이 끝날 때까지 기다린다.
   Console에 [L4D v9] 동료 AI 패치 적용 완료 메시지가 나온다.
4. 기존에 플레이하던 씬(L4D 또는 GameScene)을 다시 재생한다.
   동료는 Play 시작 시 AlliedSurvivors 아래에 Survivor_1~3으로 생성된다.
   테이블은 기존과 같이 Supplies 아래에서 생성된다.
수동 재적용 메뉴: Tools > L4D 맵 > v9 동료 AI 패치 다시 적용.

이 패키지는 기존 프로젝트에 적용하는 누적 패치다.
자동 적용기는 기존 .meta/GUID를 보존하면서 런타임 소스 36개를 한 번에 갱신한다.
기존 씬·맵 모델·저장된 NavMesh 파일은 덮어쓰지 않는다.
기존 파일의 적용 전 소스는 Unity 프로젝트의 Library/L4D_V9_Backup에 보관한다.
같은 패치는 최초 한 번만 자동 적용하므로 이후 사용자가 수정한 소스를 매번 되돌리지 않는다.

이번 수정: 동료 AI 3명
- 플레이어의 출발 위치 주변에서 동료 3명이 생성되고, 게임 진행 내내 플레이어를 따라다닌다.
- 기존 플레이어의 캐릭터 몸/Animator만 재사용한다. 복제본의 플레이어 스크립트/카메라/UI/충돌체는 제거한다.
- 모든 동료는 같은 도끼/리볼버/AR 세트를 가진다. 모두 AR로 시작하고 상황마다 다르게 선택한다.
- 근거리에서 도끼 선택 확률이 높고, 중거리는 권총/AR, 원거리는 AR 선택 확률이 높다.
- 근접/사격/이동/재장전 표시와 발사음, 총구 섬광/탄 궤적이 연결되어 있다.
- Follow / Combat / Idle의 세 상태로 관리한다. 전투 중에도 플레이어와 멀어지면 복귀를 우선한다.
- stopDistance 기본 5m: 이 거리 이상이면 플레이어를 추적한다.
- closeDistance 기본 2.8m: 이 거리 이내에서는 따라가는 이동을 멈춘다.
- 두 거리 사이에서는 직전 추적 여부를 유지해 멈춤/출발이 반복되지 않게 한다.
- 대형은 좌우/뒤로 나뉜다. 경로가 막히면 걸을 수 있는 위치/연결된 길을 재검사한다.
- 플레이어가 공격해 맞힌 적과 직접 플레이어를 때린 좀비가 10m 이내면 우선 대상으로 5초간 지정한다.
- 직접 피격을 준 적은 1.5초 동안 다른 공격 신호보다 우선한다.
- attackCooldown 기본 0.35초. 도끼/권총의 더 긴 개별 공격 간격과 AR의 짧은 연사 묶음도 적용한다.
- AR 30발/권총 6발 탄창을 별도로 관리하고, 비면 자동 장전한다. 플레이어의 보급품을 소비하지 않는다.
- 플레이어/다른 동료가 사선에 있으면 쏘지 않고 옆으로 이동할 수 있는 곳을 찾는다.
- 적이 먼저 가로막으면 실제로 먼저 맞은 적만 피해를 받는다. 벽 너머에는 대미지를 주지 않는다.
- 동료는 끝까지 호위하는 지원형이며, 이번 구현에는 동료 체력/다운 상태를 두지 않는다.
- 동료의 공격은 플레이어 공격 신호와 구별하며, 동료가 잡은 적의 피는 플레이어 렌즈에 튀지 않는다.
- 표적 판단은 약 0.16초, 경로 갱신은 약 0.25초 간격으로 나누고 살아 있는 적 목록을 공유한다.
- 원본 캐릭터 메시/애니메이터/재질은 수정하지 않는다. 무기 분리와 숨기기는 복제본에만 적용한다.

이전 v8: 처치 피와 탱크 달리기 쉐이크
- 실제 좀비 처치 순간에 화면 가장자리로 피가 튀고, 잠깐 묻은 뒤 아래로 흘러내리며 사라진다.
- 가까운 처치일수록 크고 진하다. 조준점 주변은 비워두며 HUD와 입력을 방해하지 않는다.
- 먼 뒤쪽/시야 밖 처치는 제외한다. 화면에 보이는 원거리 처치는 약하게 표시한다.
- 산탄과 폭발의 동시 다중 처치는 짧은 묶음으로 합쳐 과도하게 화면을 덮지 않게 한다.
- 투명 핏자국 네 종류를 담은 텍스처와 UI 18개를 처음에 만들고 재사용한다.
  처치마다 새 GameObject/텍스처/파티클을 생성하지 않는다.
- 피의 기본 지속 시간은 약 2.8초(조금씩 다르게), 최대 투명도 설정은 0.82다.
- 탱크가 실제로 달린 거리를 기준으로 약 2.5m마다 발소리와 묵직한 카메라 쉐이크가 함께 발생한다.
- 탱크 근처에서 강하게, 멀어질수록 약하게 흔들리고 28m 밖에서는 새 발걸음 쉐이크가 발생하지 않는다.
- 정지/공격 중, 이동 불가능한 상태와 위치 보정 순간에는 달리기 쉐이크를 만들지 않는다.
- 탱크의 기존 등장 포효/공격/사망 쉐이크는 유지한다.
- 화면 피 효과는 자동으로 붙는다. 새 Resources/Effects/ScreenBloodAtlas.png도 전체 Import한다.

이전 v7: 무기를 주워도 화면에 보이지 않던 문제
- 팔 모델이 없거나 보정 중이어도 도끼/리볼버/SMG/산탄총을 카메라 앞에 바로 표시한다.
- AR의 눈 위치 보정은 맨손/수류탄의 총 내리기 오프셋과 분리한다.
- 군인 모델을 읽거나 보정할 수 없으면 AR도 별도 기본 모델로 표시한다.
- 잘못된 손뼈 위치 때문에 들고 있는 무기가 화면 밖으로 따라가지 않게 한다.
- URP와 기본 렌더 파이프라인에서 손/무기만 그리는 카메라를 하나 사용한다.
  좀비나 벽이 바로 앞에 와도 무기가 가려지지 않도록 깊이를 따로 처리한다.
- 전용 카메라는 무기 레이어만 렌더링하며 추가 그림자/후처리를 사용하지 않는다.
  기존 레이어/씬 설정을 바꾸지 않고 사용하지 않는 런타임 레이어를 고른다.
- 미니맵에는 1인칭 무기 복제본을 표시하지 않는다.
- 수류탄도 팔 보정을 기다리지 않고 표시하며 기존 던지기/밀치기를 유지한다.
- 기존 패치 위에 전체 Import하고, 적용 완료 후 컴파일을 기다린 다음 다시 Play한다.

시작 무기 테이블
- 출발 안전가옥의 시작 위치 가까이에 무기 테이블을 만든다.
- 테이블 위에 도끼, 리볼버, AR을 놓는다.
- 처음에는 세 무기를 자동 지급하지 않는다. 물건을 바라보고 E로 주워 장착한다.
- 한 무기를 주운 후에도 다른 두 무기를 계속 주워 함께 보유할 수 있다.
- 주운 무기는 테이블에서 사라지고 무기 칸이 활성화된다.
- 맵을 수정해 테이블 공간이 없어진 경우에는 진행이 막히지 않게 기본 장비를 지급한다.

중간 보급
- 경로 전체의 실제 이동 거리를 기준으로 약 20/40/60/80% 위치 주변에 보급대를 만든다.
- 각 보급대에는 두 종류의 무기와 주변 탄약·구급상자·수류탄을 배치한다.
  1: AR + SMG / 2: 리볼버 + 산탄총 / 3: SMG + 도끼 / 4: 산탄총 + AR.
- 기존 안전가옥, 경로의 랜덤 보급품, 피날레 보급품도 유지한다.
- 바닥 높이, 실제 충돌체, NavMesh와 접근 경로를 검사한다.
- 테이블은 중심 통로에서 비켜 놓고, 동적 NavMesh 장애물로 등록해 좀비가 우회하게 한다.
- 평평하고 접근 가능한 공간이 없는 지점은 프랍 속에 강제로 배치하지 않는다.

조작
E: 바라보는 무기/아이템 습득. 가까운 거리와 시야가 필요하다.
1: 도끼 / 2: 리볼버 / 3: AR / 4: 수류탄 / 5: SMG / 6: 산탄총.
마우스 휠: 보유한 무기만 순환한다. 수류탄은 4번으로 선택한다.
R: 현재 총 재장전. 우클릭 밀치기를 사용해도 장전은 계속된다.
우클릭: 맨손과 모든 무기에서 밀치기.
Q: 구급상자 / F: 손전등. 기존 이동 조작은 유지한다.

추가 총기
- SMG: 32발 탄창, 예비탄 96발, 예비탄 최대 192발, 빠른 연사.
- 산탄총: 8발 탄창, 예비탄 32발, 예비탄 최대 64발, 클릭당 8개 산탄 발사.
- 총기별 탄창과 예비탄을 따로 관리한다. 무기를 바꿔도 탄약 수가 보존된다.
- 탄약 더미는 보유한 AR/SMG/산탄총의 예비탄을 보충한다.
- 이미 보유한 총기를 다시 주우면 탄창 한 개 분량의 예비탄을 보충한다.
  예비탄이 가득 찼거나 이미 보유한 도끼/리볼버이면 해당 물건을 소비하지 않는다.
- 기존 Resources/Weapons 모델을 우선 사용한다. 해당 모델이 없으면 기본 입체 모델을 사용한다.
  SMG/산탄총은 기본 모델과 기존 총기 효과음을 이용한 구현이다.

상호작용과 표시
- 화면 중심에 가까운 물건을 우선하므로 테이블의 무기 세 개를 각각 선택할 수 있다.
- 벽 뒤, 플레이어 뒤, 다른 층과 범위 밖의 물건은 제외한다.
- 한 번의 E키 입력이 아이템 습득과 무전기 구조 요청을 동시에 실행하지 않게 처리했다.
- 무기마다 Point Light를 추가하지 않는다. 보급품 불빛도 가까운 거리에서만 켠다.

기존 기능 유지
- 일반 좀비 속도 6, 항상 플레이어 추격.
- 탱크만 체력바와 보스 HUD 표시.
- 우클릭 밀치기, 자동차/벽 충돌 검사와 끼임 복구, 어두운 분위기.
- 기존 AR/리볼버의 장전 코드, 효과음 재사용과 미니맵 최적화.

검사와 범위
- 제공할 C# 소스 37개의 구문 검사와 56개 로직/구조 검사를 통과했다.
- 실제 C# 메서드의 제어 흐름을 모의 입력으로 실행해 습득·장착·탄약·시선 선택 등을 검사했다.
- 압축 파일 전체와 각 소스 바이트/해시, 자동 적용 후 파일 배치와 메타 보존을 검사한다.
- 이 환경에는 Unity Editor가 없어 Unity 어셈블리 컴파일, 실제 씬 플레이,
  NavMesh/물리 결과와 FPS는 확인하지 못했다. 모의 검사는 Unity 실행을 대신하지 않는다.
